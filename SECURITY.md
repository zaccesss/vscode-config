# Security Policy

## Scope

This repository is editor configuration: settings, keybindings, snippets, an extension list and
project templates. It contains no service and no library. In scope:

- An extension id in `extensions.txt` that points at a different or malicious extension
- A setting or template that runs something other than what the guides document
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in a listed extension or in VS Code itself, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
